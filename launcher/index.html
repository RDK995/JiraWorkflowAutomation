Before first launch

  • Install Docker Desktop and open it once.
  • Install Node.js so the local setup API can run.
  • Keep this launcher inside the downloaded PRonto folder, or set PRONTO_WORKSPACE_ROOT.
  • For packaged releases, make sure the setup UI bundle is included.

Setup URL: http://127.0.0.1:3010

If startup fails, the launcher will tell you whether the workspace, Node.js, or the built setup UI is missing.
